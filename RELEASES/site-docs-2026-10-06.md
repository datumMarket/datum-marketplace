# site-docs — the release that lets the site explain itself

**Date:** 2026-10-06
**Touches:** the API (`server/index.js` — two GET routes + two `/health` fields), the landing page (`web/index.html` — one Docs section).
**Does not touch:** `contracts/`, and therefore nothing on-chain. Same token, same marketplace, same addresses on Base. Not a protocol release. Not an npm release — no package version moves and **no tag** (a `v*` tag would fire the npm publish workflow for a package that did not change).

---

## What was broken

The token overview and whitepaper were published to GitHub on 2026-10-01, but datummarket.co — the canonical URL — 404'd on both. A human who found the site and wanted to understand DTM had to already know to go looking on GitHub. The landing page linked to nothing human-facing: only agent and developer surfaces.

## What is different now

- `GET /tokenomics` and `GET /whitepaper` serve the repo's `docs/TOKENOMICS.md` and `docs/WHITEPAPER.md` as `text/markdown`, through the same `serveDiscovery` mechanism that already serves `/openapi.yaml` and `/guide`. One source of truth: the repo file is the page, on GitHub and on the site.
- `/health` advertises both routes next to `llms` and `openapi`, so agents discover them too.
- The landing page gains a **Docs** section linking both.

## What is not touched

- No existing route modified or removed. Nothing changes in market, trading, auth, purchases, downloads, uploads, or search.
- No npm package change: `datum-mcp-server` stays at 1.7.1.
- The two documents themselves are unchanged — this release only makes them reachable. They were secret-scanned (canary-proven) and read-approved on 2026-10-01.

## How it was verified

Observed on a local boot of the real server (`PORT=8799`, dev chain):

- `GET /tokenomics` → **200**, `text/markdown; charset=utf-8`, body begins `# Datum (DTM) — Token Overview`
- `GET /whitepaper` → **200**, `text/markdown; charset=utf-8`, body begins `# Datum — Whitepaper`
- Regressions: `/health`, `/llms.txt`, `/openapi.yaml`, `/guide` all still **200**
- `/health` JSON now includes `tokenomics: "/tokenomics"` and `whitepaper: "/whitepaper"`
- `node --check server/index.js` passes; repo test suite passes

## Rollback

Revert the commit and redeploy. The deploy snapshots `/opt/datum` to `/opt/datum-backups/<timestamp>.tar.gz` before rsync, so the pre-deploy state is on the box.
